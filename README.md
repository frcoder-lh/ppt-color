# [PPT 配色方案生成器](https://github.com/你的用户名/ppt-color)

![banner](https://img.shields.io/badge/PPT%20配色方案生成器-PPT%20Color%20Scheme%20Generator-3a6ea5)

> 一个主色，自动生成整套网页配色。零依赖、单文件、即开即用。

---

## 它能做什么

输入一个主色，自动生成 **6 个色块**（背景、主色、点缀色 + 各自的文字色），并在三种版式里实时预览效果。

- 4 种配色方案 · 每方案 5 档强度
- 内置取色器 + 五组预设色板（中国色 / 标准色 / 莫兰迪 / 马卡龙 / 大地色）
- 自动检测文字与背景的对比度
- 自定义色导入、历史方案一键回填
- 支持导出配色 JSON

---

## 怎么用

1. 用浏览器打开 `PPT配色方案生成器.html`（Chrome / Edge / Safari 均可）
2. 点任意色块，打开取色板选色（或输入色号）
3. 在「配色方案」里选方案和档位
4. 右侧预览区切换「标准版 / 封面页 / 左栏页」看效果

> 你的配色会保存在浏览器本地，无需联网、不用注册。

---

## 技术

- 单文件 HTML，无依赖、无构建
- 桌面端左右布局 · 移动端上下布局
- 数据存于浏览器 `localStorage`
